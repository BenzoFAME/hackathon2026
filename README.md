🛰️ Orbit — платформа мониторинга спутников
📌 Описание проекта
Orbit — это backend-платформа для отслеживания спутников и прогнозирования их пролётов над заданной точкой на Земле.
Система использует реальные орбитальные данные (TLE) и физические модели для вычисления положения спутников и отображения их движения в реальном времени.
🚀 Разработано в рамках Hackathon 2026
________________________________________
⚙️ Основные возможности
•	🛰️ Отслеживание спутников
•	📍 Расчёт позиции спутника относительно наблюдателя
•	📅 Прогноз пролётов (Pass Prediction)
•	📡 Работа с TLE-данными
•	🌍 Расчёты орбит с использованием SGP4
•	🔄 WebSocket трансляция положения спутников в реальном времени
•	🔎 Фильтрация спутников (по типу, стране, орбите)

🧠 Технологии
Backend
•	Java 17+
•	Spring Boot
•	Spring Web
•	Spring Data JPA
•	WebSocket (реалтайм обновления)
Орбитальная механика
•	Orekit — библиотека для астродинамики
•	SGP4 — модель распространения орбиты

•	PostgreSQL (по конфигам IntelliJ)

🏗 Архитектура
Проект построен по классической layered-архитектуре:
Controller → Service → Repository → Database
Основные модули:
•	controller/
o	SatelliteController — API для спутников
o	AdminController — административные операции
•	service/
o	SatelliteService — бизнес-логика
o	PassPredictionService — расчёт пролётов
o	Sgp4Service — расчёт орбит
o	TleLoaderService — загрузка TLE
o	SatelliteBroadcastService — WebSocket стриминг
•	model/
o	Satellite — сущность спутника
•	dto/
o	SatelliteDto, PassPredictionDto, SatPositionDto
•	repository/
o	SatelliteRepository — работа с БД
•	config/
o	OrekitConfig — настройка Orekit
o	WebSocketConfig — WebSocket
o	CorsConfig — CORS
________________________________________
🧮 Как работает система
1.	Загружаются TLE-данные спутников
2.	Через SGP4 вычисляется положение спутника
3.	Orekit используется для точных астрономических расчётов
4.	Рассчитывается:
o	азимут
o	высота (altitude)
o	время видимости
5.	Данные:
o	отдаются через REST API
o	транслируются через WebSocket
