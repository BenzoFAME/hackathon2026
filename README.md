# 🛰 Satellite Pass Monitoring Platform

## 📌 Описание проекта

Веб-платформа для мониторинга пролётов спутников в реальном времени.

Приложение позволяет отслеживать, когда и где спутники будут видны с заданной точки на Земле, предоставляя удобную визуализацию и прогнозы на основе орбитальных данных.

> ⚡️ Разработано в рамках Hackathon 2026 как MVP системы для наблюдения за спутниками.

---

## 💡 Идея

Современные спутники активно используются в навигации, связи и научных исследованиях, однако инструменты для их отслеживания часто сложны или неудобны.

Мы создали платформу, которая:

* 📍 показывает пролёты спутников над выбранной локацией
* ⏱️ прогнозирует время видимости
* 🌍 визуализирует траекторию на карте
* 👨‍🚀 делает спутниковые данные доступными для обычных пользователей

---

## 🛠 Основные возможности

* 🛰 Отслеживание пролётов спутников в реальном времени
* 📍 Выбор любой точки на карте
* 📅 Прогноз будущих пролётов
* 🌍 Визуализация орбит и траекторий
* 📊 Отображение параметров (высота, скорость, угол наблюдения)

---

## 🧠 Технологии

*(пример на основе типичного стека — при необходимости уточни)*

* Frontend: React / Vue / HTML + CSS
* Backend: Node.js / Python (FastAPI / Flask)
* Орбитальные расчёты: SGP4 / TLE данные
* Карты: Leaflet / Mapbox / Google Maps API
* Дополнительно: REST API, WebSockets (для real-time обновлений)
